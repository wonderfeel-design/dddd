# Инструкция по управлению сайтом artdoska.ru

> Версия: июнь 2026 · Платформа: Tilda Publishing

---

## Что было реализовано в рамках кастомной разработки

### 1. Мегаменю каталога
Кастомная навигация: тёмная нижняя панель с 5 разделами + выпадающее мегаменю с левым сайдбаром и колонками подкатегорий. Все ссылки меню ведут напрямую на нужный раздел каталога без промежуточных переходов.

### 2. Страница товара
Полностью кастомная страница `/tproduct/…` — замена стандартной Tilda. Включает:
- Выбор цвета через свотчи (цветовые кнопки) с мгновенным переключением фото
- Выбор покрытия, ширины и длины через выпадающие списки
- Кнопка «Добавить в корзину» с формированием позиции: название + цвет + покрытие + ширина + длина
- Кнопка «Пробный выкрас» (добавляет услугу в корзину отдельной позицией)
- Кнопка «Палитра цветов» — переход на `/palitra` с сохранением контекста товара

**Автоматическое определение типа товара («доска» / не «доска»).** Страница сама определяет, доска перед ней (вагонка, блок-хаус, планкен и т.п. — с шириной и длиной) или нет (крепёж, фурнитура и другие штучные товары). Для «не досок» страница автоматически:
- скрывает счётчик «Погонные метры» (остаётся только «Единицы товара»);
- скрывает кнопку «Палитра цветов» и блок «Заказать пробный выкрас» — это функции покраски доски, к крепежу и подобным товарам не относятся;
- вместо выпадающих списков «Ширина / Длина / Тип покрытия» показывает выпадающие списки с реальными характеристиками этого товара (например «Размер», «Шлиц», «Фасовка» — какие есть у конкретного товара).

Никаких настроек для этого включать не нужно — переключение происходит само по полям изданий товара (см. ниже раздел «Товары без «доски»»).

### 3. Страница палитр `/palitra`
- Фильтр по бренду (Valtti, Vinha, RAL, и др.)
- При переходе с карточки товара: автоматически серятся несовместимые палитры (по типу покрытия)
- Клик на цвет в палитре → возврат на товар с уже выбранным цветом

### 4. Корзина и заказы
В каждой позиции заказа отображается полная информация:
- Название товара
- Цвет (код и название)
- Тип покрытия
- Ширина (мм)
- Длина (м)
- Количество и сумма

### 5. Сетка каталога и выравнивание
- Ширина контента — 1200 px (вместо стандартных Tilda 960 px)
- Каталог товаров: 3 карточки в ряд
- Каталог палитр: 4 карточки в ряд
- Карточки товаров: единый стиль с зелёной полосой, тенью и hover-эффектом

### 6. Стили карточек
Все карточки каталога стилизованы под дизайн: скруглённые углы, белый фон, три цветных полосы под фото, типографика GothamPro.

## Как обновлять товары

Товары управляются стандартными инструментами Tilda Магазин — никакого специального кода не требуется.

### Добавить новый товар
1. Тильда → Сайт → нужная страница каталога
2. Блок каталога → **Контент** → **Добавить товар**
3. Заполнить:
   - **Название** — отображается в карточке и в заказе
   - **Фото** — основное фото (показывается в карточке и на странице товара)
   - **Цена** — базовая (переопределяется ценой издания, если есть)
   - **Описание** — краткое описание под заголовком

### Добавить издания (варианты: цвет + покрытие + размер)
1. В карточке товара → вкладка **Издания**
2. Добавить опции: `Цвет`, `Покрытие`, `Цена за кв метр`
3. Для каждого издания заполнить:
   - `Цвет` — код цвета (например: `1012`, `5050`, `RAL 9016`)
   - `Покрытие` — тип (например: `Укрывная`, `Пропитка гидромаслом`)
   - `Цена за кв метр` — цена этого варианта
   - `Ширина (pack_y)` — ширина доски в мм (например: `96` или `122`)
   - `Длина (pack_x)` — длина в мм (например: `6000` для 6 метров)
   - **Количество** — `999999` (чтобы товар всегда был «в наличии»)
   - **Фото издания** — фото конкретного цвета/варианта

> Важно: у каждого издания должно быть указано количество `999999`, иначе товар покажется как «нет в наличии».

### Товары без «доски» (крепёж, фурнитура и т.п.)

Для товаров, у которых нет ширины/длины доски (саморезы, крепёж, любая штучная фурнитура), издания оформляются иначе — доскообразные поля `Ширина (pack_y)` и `Длина (pack_x)` просто не заполняются, и страница товара автоматически переключается в режим «не доска» (см. раздел «Страница товара» выше).

1. В карточке товара → вкладка **Издания**
2. Добавить опции с реальными характеристиками товара — любые названия, например: `Размер`, `Цвет`, `Шлиц`, `Фасовка`
3. Для каждого издания (= одна конкретная позиция на складе, один SKU) заполнить **все** эти опции строго той комбинацией значений, которая реально продаётся, например:
   - `Размер`: `3×30 мм`
   - `Цвет`: `Жёлтый цинк`
   - `Шлиц`: `Torx T10`
   - `Фасовка`: `200 шт.`
   - **Цена** этого издания
   - **Количество** — `999999`
4. **Не заполнять** `Ширина (pack_y)` / `Длина (pack_x)` — если оставить пустыми, страница сама покажет выпадающие списки по названиям опций из шага 2 вместо «Ширина/Длина».

> Важно: каждое издание должно описывать одну реальную комбинацию (SKU) целиком. Если для товара есть, например, 8 размеров с разным шлицем и фасовкой — нужно 8 изданий, каждое со своим набором значений. Страница сама подставит правильную цену и характеристики при выборе любого поля — остальные поля синхронизируются автоматически под выбранную комбинацию.

### Изменить цену
Цена издания меняется в поле каждого издания (не в общей цене товара).

### Скрыть товар
Снять галочку **Показывать** в карточке товара → **Опубликовать** блок.

## Как обновлять палитры оттенков

Палитры — это обычные товары в отдельном блоке каталога на странице `/palitra`. Управляются так же, как товары.

### Добавить новую палитру
1. Tilda → страница `/palitra` → блок каталога → **Контент** → **Добавить товар**
2. Заполнить:
   - **Название** — название палитры (например: `Vinha 2666`)
   - **Фото** — свотч (цветной квадрат/образец)
   - **Описание** — можно указать код цвета, бренд
   - **Характеристики** → `Бренд`: `Valtti` / `Vinha` / `RAL` / `Puutalot` / `Deco` (строго одно значение — используется для фильтра)
   - **Характеристики** → `Тип покрытия`: тип, с которым совместим цвет

### Изменить существующую палитру
Blok каталога → **Контент** → найти нужный товар → редактировать поля.

### Удалить палитру
В карточке товара снять галочку **Показывать** или удалить товар.

> Фильтр по бренду на `/palitra` работает автоматически по полю «Бренд» в характеристиках. Значение должно совпадать точно (без пробелов в начале/конце).

## Как менять пункты меню

Меню — кастомный код в блоке **header.html**. Редактируется вручную.

### Где находится
Tilda → Сайт → любая страница → блок хедера → **Редактировать HTML** (или через **Настройки сайта** → **Вставить код** → **В начало** `<head>` / в блок хедера).

На практике: файл `header.html` в репозитории → блок вставлен в Tilda как Zero-блок или HTML-блок шапки.

### Изменить название пункта

Найти в коде строку вида:
```html
<a href="/catalog/…" data-cat="…" data-panel="…">Для интерьера</a>
```
Изменить текст между `>` и `</a>`.

Название нужно поменять **в двух местах**:
1. В нижней навигации (`.nx-bottomnav-links`) — видно в полосе меню
2. В сайдбаре мегаменю (`.nx-megamenu-sidebar`) — видно в выпадающем меню

### Изменить ссылку пункта меню

Найти `href="/catalog/…"` и заменить на нужный адрес.

> ⚠️ Ссылки меню ведут на конкретные разделы каталога по их UID. Если раздел в Tilda Магазин переименован или пересоздан — его UID изменится, ссылку нужно обновить вручную.

### Добавить новый пункт верхнего уровня

1. В `.nx-bottomnav-links` добавить:
```html
<a href="/catalog/UID-slug" data-cat="UID" data-panel="KEY">Название</a>
```

2. В `.nx-megamenu-sidebar` добавить `<li>`:
```html
<li><a href="/catalog/UID-slug" data-panel="KEY">Название</a></li>
```

3. Добавить блок содержимого мегаменю:
```html
<div class="nx-megamenu-content" id="cat-KEY">
  <div class="nx-megamenu-col">
    <h4><a href="/catalog/…">Подраздел</a></h4>
    <ul>
      <li><a href="/catalog/…" data-cat="…">Товар</a></li>
    </ul>
  </div>
</div>
```
Где `KEY` — уникальное латинское слово (например `fasad`, `kraski`), совпадает в `data-panel` и `id="cat-KEY"`.

### Структура меню (текущая)

| Раздел | URL |
|--------|-----|
| Для интерьера | `/catalog/810291631742-dlya-interera` |
| Для фасада | `/catalog/799009129752-dlya-fasada` |
| Пиломатериалы | `/catalog/929460929152-pilomateriali` |
| Крепеж | `/catalog/559088613632-krepezh` |
| Краски | `/catalog/807847057542-kraski` |

## SEO — как добавлять мета-теги страниц

Для каждой страницы Tilda позволяет задать заголовок, описание и ключевые слова — они попадают в `<head>` и используются поисковиками.

### Где настраивается

1. Tilda → **Сайт** → нужная страница → шестерёнка (⚙) рядом с названием страницы → **Настройки страницы**
2. Вкладка **SEO**

### Поля, которые нужно заполнить

| Поле | Что писать | Пример |
|------|-----------|--------|
| **Title** | Главный заголовок страницы (до 60 символов) | `Вагонка штиль — купить в Москве · АРТ ДОСКА` |
| **Description** | Краткое описание для сниппета в поисковике (до 160 символов) | `Вагонка штиль из сосны, ольхи и лиственницы. Покраска в любой цвет. Доставка по Москве и МО.` |
| **Keywords** | Ключевые слова через запятую (необязательно, Google игнорирует) | `вагонка штиль, купить вагонку, деревянная вагонка` |
| **OG Image** | Картинка для превью в соцсетях (1200×630 px) | фото товара или логотип |

> Title и Description — самые важные поля. Заполняйте их для каждой страницы каталога и статьи блога.

### SEO для карточки товара

Карточки товаров в Tilda Магазин тоже имеют SEO-поля:

1. Блок каталога → **Контент** → нужный товар → вкладка **SEO**
2. Заполнить **Title** и **Description** для конкретного товара

Если не заполнено — Tilda подставляет название товара автоматически, но лучше указать вручную с ключевыми словами.

### Общие SEO-настройки сайта

Tilda → **Настройки сайта** → вкладка **SEO** → здесь можно задать:
- Favicon
- Глобальный Title-шаблон (`%page_title% · АРТ ДОСКА`)
- Robots.txt (управление индексацией)
- Верификацию Google Search Console / Яндекс.Вебмастер

## SEO — ведение блога (статьи в Потоках Tilda)

Блог на Tilda реализуется через инструмент **Потоки** (Tilda Blog / Zero Block Stream). Регулярные статьи помогают привлекать органический трафик по информационным запросам.

### Где находится

Tilda → **Потоки** (в левом меню сайта) → список статей.

### Как создать новую статью

1. **Потоки** → **Добавить запись**
2. Написать текст статьи в визуальном редакторе
3. Заполнить обязательные поля:
   - **Заголовок** — название статьи (он же `<h1>`)
   - **Анонс** — краткое описание (отображается в списке статей)
   - **Обложка** — фото для превью
   - **URL** — ЧПУ (человеко-понятный URL), например `/blog/kak-vybrat-vagonku`
4. Вкладка **SEO**: заполнить Title и Description
5. Нажать **Опубликовать**

### Как писать статьи, которые приносят трафик

**Выбор темы**
- Отвечайте на вопросы покупателей: «Чем отличается вагонка от имитации бруса?», «Какое покрытие выбрать для фасада?»
- Используйте Яндекс.Вордстат или Google Search Console, чтобы найти реальные запросы
- Хорошие форматы: сравнения, инструкции, подборки («Топ-5 пород дерева для бани»)

**Структура статьи**
- Заголовок H1 — чёткий, с ключевым словом
- Подзаголовки H2/H3 — логичная структура, читается «по диагонали»
- Объём — от 800 слов (короткие статьи плохо ранжируются)
- Внутренние ссылки на товары каталога (например: «купить вагонку штиль →»)
- Фото товаров с заполненным атрибутом `alt`

**SEO внутри статьи**
- Ключевое слово — в первом абзаце, в нескольких подзаголовках, в заключении
- Не злоупотреблять: 1 ключевое слово на ~150–200 слов — норма
- Title статьи = ключевой запрос + бренд: `Вагонка или имитация бруса: что выбрать · АРТ ДОСКА`
- Description — что читатель узнает из статьи, до 160 символов

**Частота публикаций**
- Минимум 1–2 статьи в месяц для стабильного роста
- Лучше писать реже, но качественно и полно, чем часто и кратко

### Продвижение статей

- Опубликуйте ссылку в соцсетях (VK, Telegram-канал)
- Добавьте ссылку на статью в карточках смежных товаров
- Обновляйте старые статьи — Яндекс ценит актуальность контента

## Работа с заявками и заказами

### Где смотреть заявки

Все заявки с сайта попадают в два места одновременно:
1. **Tilda** → **Заявки** (левое меню) — все формы и заказы из магазина
2. **Email** — на почту, указанную в настройках каждой формы

### Типы заявок

| Тип | Откуда | Где смотреть |
|-----|--------|-------------|
| Заказ из корзины | Страница товара → «Купить» | Tilda → Заявки → фильтр «Магазин» |
| Пробный выкрас | Страница товара → «Заказать выкрас» | Tilda → Заявки → фильтр «Магазин» |
| Обратный звонок / форма | Любая форма на сайте | Tilda → Заявки → фильтр «Формы» |

### Как работать с заказами в Tilda

1. Tilda → **Заявки** → выбрать нужный заказ
2. В заказе видно:
   - Контактные данные покупателя (имя, телефон, email)
   - Состав корзины: товар, цвет, покрытие, ширина, длина, количество, сумма
   - Дата и время заявки
3. Статус заказа можно менять вручную: **Новый → В работе → Выполнен / Отменён**
4. Можно добавить **комментарий** к заказу для внутреннего использования

### Уведомления о новых заявках

Настройка email-уведомлений:
- Tilda → **Настройки сайта** → **Формы** → поле **Email для уведомлений**
- Там же можно настроить текст письма покупателю (автоответ)

Для заказов из магазина:
- Tilda → **Магазин** → **Настройки** → **Уведомления** → указать email менеджера

### Экспорт заявок

Tilda → **Заявки** → кнопка **Экспорт** (правый верхний угол) → скачать CSV.  
Удобно для ведения учёта в Excel или Google Таблицах.

> Заявки хранятся в Tilda бессрочно. Для резервной копии рекомендуется экспортировать CSV раз в месяц.

## Статистика: Tilda и Яндекс.Метрика

### Встроенная статистика Tilda

Tilda → **Статистика** (левое меню) — базовые данные по сайту:

- **Просмотры и визиты** — сколько раз открывали страницы
- **Уникальные посетители** — количество людей (не страниц)
- **Конверсии** — сколько посетителей оставили заявку (в % от всех визитов)
- **Источники трафика** — откуда пришли (поиск, прямые заходы, соцсети, реклама)

Встроенная статистика Tilda ограничена — для полноценного анализа используйте Яндекс.Метрику.

### Яндекс.Метрика

#### Как открыть

1. Перейти на `metrika.yandex.ru` → войти под логином, на который зарегистрирован счётчик
2. Выбрать счётчик `artdoska.ru`

#### Основные отчёты (с чего начать)

| Раздел | Что смотреть |
|--------|-------------|
| **Сводка** | Общая картина: визиты, отказы, глубина просмотра, время на сайте |
| **Источники → Сводка** | Откуда приходят посетители (SEO, прямые, реклама, соцсети) |
| **Источники → Поисковые фразы** | По каким словам находят сайт в Яндексе |
| **Содержание → Страницы** | Какие страницы самые популярные, какие почти не просматривают |
| **Конверсии** | Сколько людей оставили заявку или добавили товар в корзину |
| **Аудитория → География** | Откуда приезжают покупатели (города) |
| **Технологии → Устройства** | Соотношение мобильных и десктопных пользователей |

#### Цели (конверсии)

Цели — это ключевые действия пользователя на сайте. Рекомендуется настроить:
- Отправка формы (заявка / обратный звонок)
- Клик «Купить» / оформление заказа
- Переход на страницу `/palitra`
- Клик по номеру телефона

Настройка: Метрика → **Настройка** → вкладка **Цели** → **Добавить цель**.

#### Что анализировать регулярно

**Еженедельно:**
- Количество визитов и заявок — есть ли рост?
- Источники трафика — что работает лучше всего?

**Ежемесячно:**
- Самые популярные товарные страницы — куда идут покупатели?
- Поисковые фразы — какие запросы приводят трафик, какие ещё нет?
- Процент отказов на мобильных — если высокий (> 60%), нужна оптимизация

**Красные флаги:**
- Резкий спад трафика → проверить индексацию в Яндекс.Вебмастере
- Высокий процент отказов (> 70%) на конкретной странице → проблема с контентом или скоростью загрузки
- Нет конверсий при наличии трафика → проверить работу форм и корзины

#### Связка с Google Search Console (по желанию)

Google Search Console показывает позиции в Google и запросы. Если сайт ориентирован на Яндекс — достаточно Метрики и Яндекс.Вебмастера. Если нужен Google — зарегистрировать сайт на `search.google.com/search-console`.

## Публикация изменений

После любого редактирования в Tilda нажать **Опубликовать** (кнопка в правом верхнем углу). Изменения применяются сразу на сайте.

Если редактировался файл кода (`head.html`, `header.html`, `all.css`) через репозиторий — после пуша нужно зайти в Tilda, найти соответствующий блок и нажать **Опубликовать** вручную (Tilda не тянет из репозитория автоматически).

**⚠️ Важно про `head.html`:** в поле кода Tilda копировать нужно **`head.min.html`**, а не `head.html`. `head.html` — это читаемая версия для разработки (с комментариями), она слишком большая и обрезается Tildой при вставке (из-за чего сайт показывал пустую страницу товара). `head.min.html` — та же логика в сжатом виде, без комментариев, помещается в лимит поля. Каждый раз, когда разработчик присылает обновление `head.html`, вместе с ним в репозитории обновляется и `head.min.html` — копировать нужно именно его.
