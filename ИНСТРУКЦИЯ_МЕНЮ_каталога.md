Файл меню: **`header-megamenu-alt.html`**
Куда вставляется в Tilda: HTML-блок (T123 / Zero Block) с меню каталога.
Публикуется **напрямую** (как `header.html` / `palitra.html`), а НЕ через `head.min.html`.

> ✅ Структура и все ссылки ниже подтверждены выгрузкой из админки Tilda (редактор разделов каталога) и заведены в код `header-megamenu-alt.html`. Раздел «Часть 2» больше не актуален — все пункты, которые раньше требовали ссылки, её получили.

## ЧАСТЬ 2. Фото пунктов меню

Часть пунктов выше (в основном новые/переименованные — Шпонированная доска в «Стены», Доска стеновая, Палубная доска, Шпунтованная доска, вся группа «Крепёж») временно используют фото соседнего похожего пункта как заглушку (см. комментарии в коде `header-megamenu-alt.html` рядом с константами `IMG_*`). Чтобы поставить настоящее фото:

1. Залить фото категории в Tilda (**Настройки сайта → Изображения**), скопировать `tildacdn`-ссылку.
2. В `header-megamenu-alt.html` найти нужный пункт по `name` в объекте `CATALOG` и заменить его `image` на новую ссылку.

## ЧАСТЬ 3. Как редактировать меню (в коде)

Всё меню задаётся данными в файле `header-megamenu-alt.html` — искать блок `var CATALOG = [ … ]`.

### 3.1. Из чего состоит один пункт

```js
{name:'Вагонка', h:'/catalog/752465215952-vagonka', image:'https://…'}
```
- `name` — что видно в меню (текст пункта).
- `h` — ссылка каталога (куда ведёт).
- `image` — картинка (прямая ссылка, лучше `tildacdn`).

Подраздел (Потолок / Стены …) выглядит так:
```js
{ heading: 'ПОТОЛОК', href: '/catalog/565173393412-potolok', items: [
    {name:'Вагонка', h:'/catalog/752465215952-vagonka', image:'https://…'},
    {name:'Планкен', h:'/catalog/228699182612-planken', image:'https://…'}
] }
```
- `heading` — заголовок подраздела.
- `href` — ссылка на весь раздел (клик по заголовку).
- `items` — список пунктов.

Верхний уровень (вкладка в баре):
```js
{ key: 'interier', label: 'ДЛЯ ИНТЕРЬЕРА', href: '/catalog/810291631742-dlya-interera', subCats: [ … ] }
```

### 3.2. Добавить пункт
Внутри нужного `items: [ … ]` дописать новую строку через запятую:
```js
{name:'Оконный щит', h:'/catalog/ЦИФРЫ-slug', image:'https://…'},
```

### 3.3. Удалить пункт
Удалить всю строку `{name: … }` целиком (вместе с запятой).

### 3.4. Переименовать пункт / поменять ссылку
Поменять текст в `name` или адрес в `h`:
```js
{name:'Брус', …}   →   {name:'Бруски', …}
h:'/catalog/старая'  →   h:'/catalog/новая'
```

### 3.5. Как поменять картинку пункта
Заменить значение `image` у пункта на новую ссылку (лучше — загруженную в Tilda `tildacdn`-ссылку, внешние иногда блокируются).

### 3.6. После правок
1. Сохранить файл `header-megamenu-alt.html`.
2. Вставить его содержимое в тот же HTML-блок в Tilda (где сейчас меню).
3. **Опубликовать** страницу.

## Примечание про `header.html`

В репозитории также есть файл `header.html` — это более ранняя, не обновлявшаяся версия меню (в её разделе «Крепёж» до сих пор фигурируют несуществующие названия вроде «Скобы»/«Гвозди»/«Клипсы»). Она не используется — актуальный код только в `header-megamenu-alt.html`.
