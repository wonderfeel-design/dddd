## Как редактировать меню (в коде)

Всё меню задаётся данными в файле `header-megamenu-alt.html` — искать блок `var CATALOG = [ … ]`.

### Из чего состоит один пункт

```js
{ name: 'Вагонка', image: 'https://…tildacdn…', h: '/catalog/752465215952-potolok-vagonka' }
```
- `name` — что видно в меню.
- `image` — картинка (полная tildacdn-ссылка).
- `h` — ссылка каталога (`/catalog/<uid>-<slug>`).

Подкатегория (Потолок / Стены …):
```js
{ heading: 'ПОТОЛОК', href: '/catalog/565173393412-potolok', items: [
    { name: 'Вагонка', h: '/catalog/752465215952-potolok-vagonka', image: '…' },
    { name: 'Планкен', h: '/catalog/228699182612-potolok-planken', image: '…' }
] }
```
- `heading` — заголовок подкатегории.
- `href` — ссылка на весь раздел (клик по заголовку).
- `items` — список пунктов.

### Добавить / удалить / изменить пункт
Внутри нужного `items: [ … ]` дописать/удалить строку `{ name: …, h: …, image: … }` целиком
(вместе с запятой). Переименование/смена ссылки — правка `name`/`h` на месте.

### После правок
1. Сохранить файл `header-megamenu-alt.html`.
2. Вставить его содержимое в тот же HTML-блок в Tilda (где сейчас меню).
3. **Опубликовать** страницу.
